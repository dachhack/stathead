# User preferences

## Explain git operations

The user is a git novice. When performing git actions beyond basic `status`/`add`/`commit`/`push`, explain what the command does and why it's needed before (or alongside) running it. In particular, when doing:

- `rebase` / `cherry-pick` / `reset` / `revert` / force-push
- Resolving merge conflicts
- Dealing with squash vs merge vs rebase-merge trade-offs
- Any operation that rewrites history

...narrate the reasoning in plain language as if teaching. Keep explanations concise but don't skip the "why".
